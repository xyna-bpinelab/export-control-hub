EARでは、品目と仕向地で許可が要らなくても、<strong>取引の相手（エンドユーザー）</strong>や<strong>用途（エンドユース）</strong>によって許可が必要になります（一般禁止事項4・5・7、15 CFR Part 744）。EAR99 の品目も対象です。

日本のキャッチオール（[03 キャッチオール規制](../../03-catch-all/)）に近い仕組みですが、EARでは**リストに載った相手との取引に、それだけで許可が必要**になる点が大きく違います。

> 2026年10月19日時点の eCFR（15 CFR Part 744）をもとに整理しています。

## 制裁リストの比較

| リスト | 根拠 | 掲載されると | 許可例外 |
|---|---|---|---|
| **Entity List** | § 744.11・Part 744 補足4 | リストの「License Requirement」欄の範囲（多くは**EAR対象のすべての品目**）で許可が必要。審査方針は多くが**原則不許可**（presumption of denial） | 原則使えない（掲載ごとに指定） |
| **MEU List**（軍事エンドユーザー） | § 744.21・Part 744 補足7 | Part 744 補足2 の品目（EAR99 の一部を含む）で許可が必要 | 原則使えない |
| **Unverified List**（UVL） | § 744.15・Part 744 補足6 | 許可不要の取引でも、相手から**UVL 声明書**（用途・需要者の申告、事後検査への協力 等）を取ってから出荷 | **使えない**（§ 740.2(a)(17)） |
| **Denied Persons List** | Part 764・766 | **取引禁止命令**。EAR対象品目に関わる取引のすべてが禁止 | なし（一般禁止事項4） |
| SDN List（財務省 OFAC） | § 744.8 等 | OFAC の資産凍結。EARでも一部のプログラムの SDN 向けに許可が必要 | 原則使えない |

{{% callout type="tip" title="スクリーニングは一括検索で" %}}
米国政府の [Consolidated Screening List](https://www.trade.gov/consolidated-screening-list) で、Entity List・MEU List・UVL・Denied Persons・SDN 等をまとめて検索できます。社名の**別名・旧社名・住所**でも確認します（Entity List には別名や住所ごと掲載されている例が多い）。**日本国内の法人**が掲載されている例もあります（例：Huawei Technologies Japan K.K.）。
{{% /callout %}}

## Entity List の50%ルール（Affiliates ルール）

| 項目 | 内容 |
|---|---|
| 内容 | Entity List・MEU List の掲載者（又は一部の SDN）が、**直接・間接に、単独又は合計で50%以上**を所有する外国の会社にも、掲載者と同じ規制が及ぶ（§ 744.11(a)(1)、Part 744 補足8） |
| 複数の掲載者が所有 | 所有者に適用される規制のうち、**最も厳しいもの**が適用される |
| 所有割合がわからない | 掲載者が所有に関わっている可能性があるなら、割合を確認するか、許可を取るなど慎重に対応する |
| 経緯 | 2025年9月29日施行の暫定最終規則で導入。2025年11月12日の官報で、**2025年11月10日から2026年11月9日まで1年間停止**。延長がなければ **2026年11月10日から再び適用**される |

{{% callout type="danger" title="停止期間の終わりに注意" %}}
50%ルールの停止は **2026年11月9日まで**です。延長するかどうかは官報（Federal Register）と [BIS のお知らせ](https://www.bis.gov/news-updates)で必ず確認してください。再び適用されると、Entity List に名前が載っていない会社でも、**株主構成によって**許可が必要になります。取引先の株主（最終的な所有者）の確認手順を、今のうちに整えておきます（→ [株主確認の手順](../ownership-check/)）。
{{% /callout %}}

## 懸念用途・懸念需要者（Part 744）

品目が EAR99 でも、次の用途・需要者向けだと**知っている**（knowledge）場合は、許可が必要です。EARの「knowledge」は、確実に知っていることだけでなく、**知り得べき理由がある**（reason to know）場合も含みます（§ 772.1）。

| 条 | 用途・需要者 | 対象の地域 |
|---|---|---|
| § 744.2 | 核爆発装置、保障措置のない核活動 等 | 補足3 の国（日本を含む同盟国）以外 |
| § 744.3 | ミサイル・ロケット・無人航空機の開発等 | 国グループ D:4 等 |
| § 744.4 | 化学・生物兵器 | 全世界 |
| § 744.21 | **軍事エンドユース・軍事エンドユーザー** | **中国**・ミャンマー・カンボジア・ニカラグア・ベネズエラ（補足2 の品目）、**ロシア・ベラルーシ**（EARの対象のすべての品目） |
| § 744.22 | **軍事情報**のエンドユース・エンドユーザー | ベラルーシ・ミャンマー・カンボジア・中国・ロシア・ベネズエラ、国グループ E:1・E:2 |
| § 744.23 | スーパーコンピュータ・先端ノード IC の製造・半導体製造装置の用途 | 中国・マカオ・D:5 等 |

{{% callout type="warning" title="BIS からの通知（is-informed）" %}}
BIS から個別に「この取引には許可が必要」と**通知**された場合も、許可が必要になります（日本のインフォーム要件と同じ考え方）。
{{% /callout %}}

### レッドフラッグ（Part 732 補足3「Know Your Customer」）

次のような兆候があれば、確認してから取引します。解消できなければ、出荷を止めるか BIS に相談します。

| 兆候の例 |
|---|
| 顧客や住所が Entity List 等の掲載者と**似ている** |
| 顧客が品目の**用途を明かしたがらない** |
| 品目の性能が、顧客の事業内容に**見合わない** |
| 高価な品目なのに**現金払い**を申し出る |
| 顧客に事業の実績がほとんどない |
| 据付・研修・保守を**断る** |
| 納期・納入先があいまい、又は運送業者が最終仕向地になっている |
| 輸送経路が品目・仕向地に照らして**不自然** |
| 梱包・表示が通常と違う |
| 再輸出の有無を聞いても答えがはっきりしない |

{{% callout type="danger" title="知らなかったでは済まない" %}}
レッドフラッグを**意図的に無視**した（self-blinding）場合も、knowledge があったと扱われます。疑問を解消した経緯は記録に残します。
{{% /callout %}}

## 米国人の活動規制（§ 744.6）

**米国人**（U.S. person：米国市民・永住権者、米国法人とその外国支店、米国内にいる人）は、物の輸出がなくても、次の活動を**支援**（support）することが禁止されています（BIS の許可が必要）。

| 活動 | 対象 |
|---|---|
| 核爆発装置の開発・製造等 | 補足3 の国以外 |
| ミサイルの開発・製造等 | D:4・E:2 の国 |
| 化学・生物兵器の開発・製造等 | 全世界 |
| 化学兵器前駆体の工場 | A:3 以外 |
| 軍事情報のエンドユース・エンドユーザー | § 744.22 の国 |
| 先端ノード IC の開発・製造、半導体製造装置 等 | マカオ・D:5（BIS の通知による。§ 744.6(c)(2)） |

「支援」には、出荷・輸送・移転のほか、**役務の提供**（保守・修理・サービス）も含まれます。日本法人に勤める**米国籍の社員**や、米国企業の日本子会社の駐在員にも関わります。

## 日本企業のチェックリスト

| # | 確認すること |
|:-:|---|
| 1 | 取扱品目に**米国原産品・米国技術**が含まれるか（部品表・ソフトウェア・設計ツール） |
| 2 | 米国原産品の **ECCN** を仕入先から入手しているか（輸入時の書類・仕入先への問い合わせ） |
| 3 | 自社製品の**米国原産比率**（デミニミス）を、仕向地ごとに計算・記録しているか |
| 4 | 設計・製造に米国の技術・ソフトウェア・装置を使っており、**直接製品ルール**に当たり得るか |
| 5 | 取引相手を **Entity List・MEU List・UVL・Denied Persons・SDN** でスクリーニングしているか（別名・住所・**親会社**を含む） |
| 6 | 用途・需要者が Part 744 の**懸念用途**に当たらないか、レッドフラッグはないか |
| 7 | 米国由来の技術を、第三国の国籍の社員に開示していないか（**みなし再輸出**） |
| 8 | 許可例外を使う場合、**条件と記録**がそろっているか |
| 9 | EARの手続を<strong>社内規程（CP）</strong>に組み込んでいるか（→ [07 社内体制](../../07-compliance-cp/)） |
