## 個別 vs 包括

{{< tabpane text=true >}}
{{% tab header="個別許可" %}}
| 項目 | 内容 |
|---|---|
| 単位 | 取引（契約）ごと |
| 対象 | 全品目・全仕向地 |
| 審査期間 | 標準処理期間 **90日**（事前相談で短縮・円滑化） |
| 有効期間 | 原則 **6か月** |
| 向いている | 取引が単発、仕向地がグループD、機微度が高い |
{{% /tab %}}
{{% tab header="包括許可" %}}
| 項目 | 内容 |
|---|---|
| 単位 | 一定の品目・仕向地の組合せをまとめて |
| 対象 | 包括許可の種類ごとに品目・仕向地が限定 |
| 前提 | 輸出管理体制（CP・自己管理チェックリスト 等） |
| 有効期間 | 原則 **3年** |
| 向いている | 同じ品目を継続的・反復的に輸出する |
{{% /tab %}}
{{< /tabpane >}}

## 包括許可の種類

| 種類 | 概要 | 主な前提 |
|---|---|---|
| 一般包括許可 | 別表A/Bで「一般」の品目 × グループA（輸出令別表第3）向け | 輸出者等概要・自己管理チェックリストの提出 |
| 特別一般包括許可 | 別表A/Bで「一般」の組合せ（輸出令別表第3の2・第4の地域は除く） | **CP（輸出管理内部規程）の受理**＋チェックリスト |
| 特定包括許可 | 継続的な取引関係にある特定の相手先向け | CP受理 等 |
| 特別返品等包括許可 | 返品・修理品の返送 等 | CP受理 等 |
| 特定子会社包括許可 | 日本企業の海外子会社向け | CP受理 等 |

{{% callout type="note" %}}
包括許可の種類・対象品目・対象地域は、通達「**包括許可取扱要領**」と、その<strong>別表A（貨物包括マトリクス）・別表B（役務包括マトリクス）</strong>で定められ、改正されます。申請前に最新版を確認してください（→ [09 関連法令](../09-laws/#包括許可の対象はどこで決まるか)）。
{{% /callout %}}

## 特別一般包括許可が効力を失う場合（別表３（１２））

特別一般包括輸出・役務（使用に係るプログラム）取引許可には、包括許可取扱要領の**別表３**で条件が付いています。そのうち**（１２）**は、貨物・技術が核兵器等の開発等やその他の軍事用途に使われる場合、又は需要者が軍関係の場合に、その輸出・取引について包括許可が**失効**するか、**届出**・**報告**が必要になるかを、表で定めています（輸出令別表第1の16の項(1)の貨物とその技術は除きます）。

> 包括許可取扱要領（最終改正：輸出注意事項2025第27号、2026年2月14日施行）の別表３をもとに整理しています。

### （表１）用途に懸念がある場合

| 用途に使われる程度 | 仕向地（提供地） | 核兵器等の開発等 | その他の軍事用途 |
|---|---|---|---|
| **用いられる**（利用される）場合 | グループA（輸出令別表第3の地域） | **失効** | 報告 |
| 〃 | 上記以外 | **失効** | **失効** |
| 用いられる（利用される）**おそれ**がある場合 | グループA | **失効**（注２） | （空欄） |
| 〃 | 上記以外 | **失効** | （空欄） |
| 用いられる（利用される）**疑い**がある場合 | グループA | 届出 | 報告 |
| 〃 | 上記以外 | 届出 | 届出 |

| 用語・注 | 内容（要約） |
|---|---|
| 失効（注１） | その輸出・取引について、包括許可が効力を失う（**個別許可が必要**） |
| 届出（注１） | その輸出・取引の**前に**経済産業大臣へ届け出る |
| 報告（注１） | その輸出・取引の**後に**内容を経済産業大臣へ報告する |
| **（注２）** | 核兵器等の開発等に用いられる（利用される）おそれがあるとして**経済産業大臣から通知を受けたときに限り**、失効する |
| 核兵器等の開発等（１）） | 核兵器、軍用の化学製剤・細菌製剤、これらの散布装置、これらを運搬できる射程・航続距離300km以上のロケット・無人航空機の開発、製造、使用又は貯蔵 |
| その他の軍事用途（１）） | 輸出令別表第1の**1の項**の貨物（スポーツ・狩猟用の銃、産業用銃、産業用の火薬類 などを除く）の開発、製造又は使用（核兵器等の開発等を除く） |
| 用いられる場合（２）） | 契約書や入手した文書などに記載がある場合、又は輸入者・需要者などから連絡を受けた場合 |
| **おそれがある場合（３））** | 2）以外で、貨物が**核兵器等開発等省令**（技術は平成13年告示第759号）に該当する場合、又は**核兵器等の開発等**に用いられるおそれがあるとして経済産業大臣から通知を受けた場合 |
| 疑いがある場合（４）） | 2）・3）以外で、核兵器等の開発等やその他の軍事用途に用いられる疑いがある場合 |

{{% callout type="info" title="表１の読み方" %}}
- 「**失効**」になるのは、「用いられる」場合（グループAのその他の軍事用途を除く）と、核兵器等の開発等に「用いられるおそれ」がある場合だけです。
- グループA向けで核兵器等の開発等の「おそれ」がある場合は、（注２）により**経済産業大臣の通知を受けたときだけ**失効します。
- 「おそれ」の定義（３））は**核兵器等の開発等**についてだけ置かれています。そのため、**その他の軍事用途の「おそれ」の欄は空欄**で、失効・届出・報告のいずれも定められていません。
- 「**疑い**」の段階では失効せず、**届出**（事前）か**報告**（事後）です。
{{% /callout %}}

### （表２）需要者が軍・軍関係機関の場合

（表１）のどれにも当たらなくても、需要者（利用する者）が**軍若しくは軍関係機関又はこれらに類する機関**の場合は、仕向地が**グループA以外**なら**届出**が必要です。ただし、ストック販売で需要者が軍関係機関であるおそれが少ないと認められる場合は届出不要です（注３）。

{{% callout type="tip" title="例：9項(1)の通信装置を特別一般包括許可で輸出する" %}}
特別一般包括許可を使える輸出令別表第1の9の項(1)の通信装置を、海外のメーカーに輸出する場合です。

| 仕向地 | 区分 | 用途 | 程度 | 表１の欄 | 失効するか |
|---|---|---|---|---|---|
| スイス | グループA | その他の軍事用途 | おそれ | 空欄 | **失効しない**（「おそれ」は核兵器等の開発等についてだけ定義されている） |
| インド | グループA以外 | 核兵器等の開発等 | おそれ | 失効 | **失効する** |
| フランス | グループA | 核兵器等の開発等 | 疑い | 届出 | **失効しない**（輸出の前に届出が必要） |

同じ「核兵器等の開発等」でも、仕向地（グループAかどうか）と、懸念の程度（用いられる／おそれ／疑い）によって結果が変わります。
{{% /callout %}}

## 申請の流れ

```mermaid
flowchart LR
  A["該非判定・<br/>取引審査"] --> B["事前相談<br/>（必要に応じて）"]
  B --> C["申請書類の準備"]
  C --> D["電子申請<br/>（NACCS）"]
  D --> E["審査<br/>（追加資料の照会）"]
  E --> F["許可証の交付"]
  F --> G["通関・輸出<br/>（許可条件の遵守）"]
```

## 主な提出書類（個別許可の例）

| 書類 | 目的 |
|---|---|
| 輸出許可申請書 | 申請の本体 |
| 申請理由書 | 取引の概要・用途の説明 |
| 契約書・注文書の写し | 取引の実在性 |
| 仕様書・カタログ | 該当項番とスペックの確認 |
| 該非判定書（パラメータシート） | 判定根拠 |
| 需要者の誓約書 | 最終用途・再輸出しない旨の確認 |
| 需要者の概要資料 | 事業内容・懸念の有無の確認 |

{{% callout type="warning" title="申請時の注意" %}}
- **許可を受ける前に**契約締結はできても、出荷・技術提供はできません。納期は審査期間を見込んで設定します。
- 許可の**条件**（再輸出の制限・報告義務 等）は、出荷後も守る必要があります。
- 申請内容と実際の取引（数量・需要者・仕向地）が違うと、許可の効力が及ばず無許可輸出になり得ます。
{{% /callout %}}
