| 代表品目 | 着眼点（例） |
|---|---|
| ガスタービンエンジン（航空機用） | 設計・技術（高温部品） |
| 人工衛星・宇宙機 | 宇宙用に設計した機器・部分品 |
| ロケット推進装置 | 4項に当たらないものも対象になり得る |
| 無人航空機・その部分品 | 航続距離・自律飛行 等（4項との関係も確認） |
| 試験装置 | エンジン試験設備 等 |

{{% callout type="warning" %}}
13項は<strong>技術（設計・製造技術）</strong>の規制が特に重要な分野です。貨物を輸出しなくても、図面・データの提供で許可が必要になることがあります（→ [04 役務取引](../../04-technology-transfer/)）。
{{% /callout %}}
