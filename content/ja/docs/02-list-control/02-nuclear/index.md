| 項目 | 内容 |
|---|---|
| 根拠 | 輸出令別表第1 2項 |
| レジーム | 原子力供給国グループ（NSG） |
| 特徴 | **民生の汎用品**（工作機械・測定機・ポンプ等）が多く含まれる |

## 代表品目としきい値の例

| 品目 | 判定の着眼点（例） |
|---|---|
| 核燃料物質・核原料物質 | ウラン・トリウム・プルトニウム等 |
| 原子炉・その部分品 | 原子炉用に設計した機器 |
| 遠心分離機・関連部品 | ウラン濃縮用の設計・材料 |
| 周波数変換器（インバーター） | 多相出力・高周波数（**600Hz以上**等）・周波数制御精度 |
| 数値制御工作機械 | 位置決め精度・制御軸数 |
| 測定装置（三次元測定機等） | 測定精度（不確かさ） |
| 真空ポンプ・圧力計 | 耐食性（フッ素系ガス対応）・材質 |
| アイソスタティックプレス | 最大圧力・チャンバー内径 |
| 高速度カメラ・フラッシュX線 | 撮影速度等 |

{{% callout type="case" %}}
三次元測定機が2項に該当するのに適切な許可を得ずに輸出され、最終的に核開発関連の懸念先へ渡った事例があります（→ [08 違反事例](../../08-penalties-cases/)）。
{{% /callout %}}

{{% callout type="tip" %}}
工作機械・測定機・インバーターは **2項と6項・7項の両方**で確認します。2項のほうが厳しい基準になる品目もあります。
{{% /callout %}}
