---
title: 14項：その他
linkTitle: 14項 その他
weight: 15
description: 軍需品に関連する物資（火薬原料・金属燃料・催涙剤など）
---

| 代表品目（例） | 補足 |
|---|---|
| 粉末状の金属燃料 | 粒径・純度 |
| 火薬・爆薬の成分・添加剤 | 特定の化学物質 |
| ディーゼルエンジン | 特定の軍用車両向け性能 |
| 自給式の潜水用具 | 閉回路式 等 |
| 催涙剤・暴動鎮圧用の物質 | 特定の化学物質 |

{{% callout type="note" %}}
14項は、武器（1項）に直接は当たらないものの軍事利用と関係の深い物資をまとめた項です。具体的な品目は輸出令別表第1・貨物等省令で確認してください。
{{% /callout %}}
