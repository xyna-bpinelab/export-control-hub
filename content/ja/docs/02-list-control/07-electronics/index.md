| 代表品目 | 着眼点（例） |
|---|---|
| 集積回路 | 耐放射線（トータルドーズ **5×10³ Gy(Si)以上** 等）、使用温度範囲 |
| FPGA・ADコンバーター等 | 入出力数・変換速度・分解能 |
| マイクロ波用部品・増幅器 | 周波数帯・出力 |
| 信号発生器・スペクトラムアナライザー等 | 周波数範囲・性能 |
| 半導体製造装置 | 露光・成膜・エッチング・洗浄等の性能 |
| 超電導材料・電子管 | 臨界温度・構造 |

{{% callout type="note" title="近年の改正：先端半導体製造装置" %}}
2023年7月施行の省令改正で、**先端半導体の製造装置など23品目**が追加されました（EUV関連、成膜、エッチング、洗浄 等）。リスト規制なので仕向地を問わず許可が必要です。包括許可が使えるかは品目・仕向地ごとに異なるため、個別に確認してください。
{{% /callout %}}

{{% callout type="warning" %}}
半導体関連は改正が続いている分野です。**装置だけでなく部分品・ソフトウェア・技術**も対象になっていないか確認してください。
{{% /callout %}}
