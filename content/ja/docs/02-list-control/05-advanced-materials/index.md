linkTitle: 5項 先端材料

description: 炭素繊維・特殊合金・ふっ素化合物製品などの材料とその製造装置
---

| 代表品目 | 着眼点（例） |
|---|---|
| 炭素繊維・アラミド繊維等 | 比弾性率 **12.7×10⁶m超** かつ 比強度 **23.5×10⁴m超**（炭素繊維等） |
| プリプレグ・複合材料 | 繊維の性能・樹脂の耐熱性 |
| ふっ素化合物製品 | 航空機・宇宙用のシール・ガスケット等 |
| 特殊合金・金属粉末 | 組成・耐熱性・粒径 |
| 芳香族ポリイミド等の樹脂 | 耐熱性（ガラス転移点） |
| 材料製造装置 | 繊維製造装置、複合材料成形装置 |

{{% callout type="tip" %}}
材料は**メーカーのデータシート値**で判定することが多い品目です。測定条件（温度・試験規格）が省令の定義と一致しているか確認します。
{{% /callout %}}
