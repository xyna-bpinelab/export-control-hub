| 項目 | 内容 |
|---|---|
| 根拠 | 輸出令別表第1 1項 / 外為令別表 1項 |
| レジーム | ワッセナー・アレンジメント（軍需品リスト） |
| しきい値 | **なし**（品目に当たれば該当） |
| 特例 | 少額特例などは原則使えない |

## 主な対象

| 区分 | 例 |
|---|---|
| 銃砲・弾薬 | 銃砲（**猟銃・競技用銃を含む**）、銃砲弾、その部分品 |
| 爆発物 | 爆弾、魚雷、地雷、ミサイル、発射装置 |
| 火薬類 | 軍用火薬・爆薬・推進薬 |
| 軍用装備 | 軍用車両、軍用船舶、軍用航空機、それらの部分品 |
| 防護具 | 防弾衣、軍用ヘルメット、装甲板 |
| その他 | 軍用探照灯、軍用の化学・生物・放射性製剤、指向性エネルギー兵器 等 |

{{% callout type="warning" title="判定のつまずきポイント" %}}
- 「**軍用に設計した**」部分品・附属品も対象。汎用品に見えても、軍用品向けに設計していれば該当し得ます。
- 猟銃・散弾・空気銃の一部も1項。スポーツ用品として扱わないこと。
- 武器の製造・使用に係る**技術**も外為令別表1項で規制されます。
{{% /callout %}}
