---

| 代表品目 | 着眼点（例） |
|---|---|
| 加速度計 | バイアス安定性・測定範囲 |
| ジャイロスコープ | ドリフト率・角速度範囲 |
| 慣性航法装置（INS） | 位置誤差（CEP）・GNSS非依存の性能 |
| 衛星測位（GNSS）受信機 | 暗号解読機能・適応アンテナ（耐妨害） |
| 航空機用電子機器 | 飛行制御・ヘッドアップディスプレイ 等 |

{{% callout type="tip" %}}
ロボット・自動運転・測量機器に組み込まれる**MEMSジャイロ・IMU**が見落とされやすい品目です。部分品単体の輸出時に確認してください。
{{% /callout %}}
