## 代表品目

| 区分 | 例 |
|---|---|
| 完成品 | ロケット、無人航空機（一定の航続距離等） |
| 部分品 | 多段ロケットの段、再突入体、誘導装置 |
| 推進 | 固体・液体ロケットの推進装置、推進薬・その原料 |
| 製造・試験 | 振動試験装置、風洞、フィラメントワインディング装置 |
| 関連 | 耐熱複合材料、航法装置（一部） |

{{% callout type="warning" title="判定のつまずきポイント" %}}
- 農業用・産業用の**無人ヘリコプター・ドローン**も、性能（航続距離・積載能力・自律飛行等）によっては該当し得ます。
- 10項・11項・13項との重複確認を忘れずに。
