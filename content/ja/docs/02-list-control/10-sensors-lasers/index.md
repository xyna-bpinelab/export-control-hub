| 代表品目 | 着眼点（例） |
|---|---|
| 赤外線カメラ・焦点面アレイ | 検出波長・画素数・フレームレート |
| 光検出器 | 波長帯・感度・宇宙用設計 |
| 高速度カメラ | 撮影速度・分解能 |
| レーザー | 波長・出力・パルス幅 |
| 音波利用機器（ソナー等） | 探知距離・周波数 |
| 磁力計・重力計 | 感度・分解能 |
| レーダー | 周波数・機能（合成開口 等） |

{{% callout type="warning" title="判定のつまずきポイント" %}}
<strong>サーモグラフィー（赤外線カメラ）</strong>は産業・医療用途でも該当することがあります。フレームレート制限版など、非該当に設計した機種かどうかを確認します。
{{% /callout %}}
