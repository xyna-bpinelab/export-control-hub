| 代表品目（例） | 分野 |
|---|---|
| 電波吸収材・導電性高分子（ステルス材料） | 材料 |
| 特定の繊維・複合材料の成形品 | 材料 |
| 水中探知装置（ソナー） | センサー |
| 宇宙用の光検出器 | センサー |
| 潜水艇関連の特定装置 | 海洋 |
| ラムジェット・スクラムジェットエンジン | 推進 |

{{% callout type="warning" title="申請時の注意" %}}
15項は**機微度が最も高い汎用品**です。5〜13項と同じ製品分野でも15項に該当すると、包括許可や特例の範囲が狭くなります。判定時は5〜13項と**並行して**確認してください。
{{% /callout %}}
