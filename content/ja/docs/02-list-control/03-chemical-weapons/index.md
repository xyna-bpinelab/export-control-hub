| 項目 | 内容 |
|---|---|
| 根拠 | 輸出令別表第1 3項 |
| レジーム | オーストラリア・グループ（AG）／化学兵器禁止条約（CWC） |
| 二本柱 | ①原料となる**化学物質** ②**化学製造設備** |

{{< tabpane text=true >}}
{{% tab header="① 化学物質" %}}
| 例 | 用途（民生） |
|---|---|
| ふっ化水素 | 半導体洗浄・エッチング |
| シアン化ナトリウム | めっき・金属精錬 |
| トリエタノールアミン | 化粧品・洗剤 |
| 三塩化りん | 農薬・難燃剤原料 |

身近な工業薬品が多い点に注意。**混合物は濃度基準**で判断します。
{{% /tab %}}
{{% tab header="② 製造設備" %}}
| 設備 | 着眼点（例） |
|---|---|
| 反応器 | 内容積 **0.1m³超〜20m³未満** ＋ 接液部が耐食材料 |
| 貯蔵容器 | 内容積 **0.1m³超** ＋ 耐食材料 |
| 熱交換器・蒸留塔・吸収塔 | 伝熱面積・内径 ＋ 耐食材料 |
| バルブ・ポンプ | 口径・材質・シール構造 |

**耐食材料**の例：ニッケル含有率40%超の合金、ふっ素樹脂、ガラス（ライニング）、タンタル、チタン 等
{{% /tab %}}
{{< /tabpane >}}

{{% callout type="warning" title="判定のつまずきポイント" %}}
容量が基準内でも「**接液部の材質**」で該当が決まります。ライニング（内張り）も材質に含めて確認してください。
{{% /callout %}}
