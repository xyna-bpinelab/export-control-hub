## 生物製造設備の代表例

| 設備 | 着眼点（例） |
|---|---|
| 発酵槽（培養装置） | 容量 **20L以上**、定置で滅菌・殺菌可能 等 |
| 連続式遠心分離機 | 処理能力、定置滅菌、エアロゾル封じ込め |
| クロスフローろ過装置 | 有効ろ過面積、定置滅菌 |
| 凍結乾燥機 | 蒸気凝縮能力（24時間あたり）、定置滅菌 |
| 噴霧乾燥器（スプレードライヤー） | 水分蒸発能力、粒子径、**定置した状態で滅菌・殺菌可能か** |
| 安全キャビネット | クラスIII 相当 |

{{% callout type="case" title="解釈が争われた事例" %}}
噴霧乾燥器の「定置した状態で内部の滅菌又は殺菌をすることができる」の解釈をめぐり、企業関係者が逮捕・起訴され、のちに起訴が取り消された事件があります。国家賠償訴訟で捜査の違法性が認定されました（→ [08 違反事例](../../08-penalties-cases/)）。
{{% /callout %}}

{{% callout type="tip" %}}
条文の用語（「定置した状態で」「滅菌」「殺菌」等）は**運用通達の解釈**まで確認し、判断に迷う場合は経済産業省に事前相談（該非の確認）をして記録を残します。
{{% /callout %}}
